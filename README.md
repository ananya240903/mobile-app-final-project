# Mobile App Final Project — Pocket Recipes

Pocket Recipes is an Expo / React Native mobile application created for the final peer-graded project. It demonstrates sign-up and login, a home screen, item details, favorites with persistent local storage, external API integration, a settings menu and settings screen, and local notifications.

## Main features

- Sign up with username, email, and password
- Login with validation and error messages
- Home screen with app branding and recipes loaded from an external API
- Detail screen for individual recipes
- Favorites / profile screen
- AsyncStorage persistence for saved favorites and settings
- Settings menu and configurable settings
- Local notification permission and test-notification workflow

## Tech stack

- React Native with Expo
- React Navigation
- AsyncStorage
- Expo Notifications
- DummyJSON Recipes API

## Run locally

```bash
git clone https://github.com/ananya240903/mobile-app-final-project.git
cd mobile-app-final-project
npm install
npx expo start
```

Use Expo Go on an Android phone or an Android emulator to run the project.
